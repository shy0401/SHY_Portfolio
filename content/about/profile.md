## 개요

전북대학교 IT정보공학과 4학년 1학기 재학중인 신하윤입니다. 보안 분야를 단순히 “관심 분야”로만 두지 않고, 웹해킹, 리버싱, 디지털 포렌식, 보안관제, 문서화 역량을 서로 연결해 사이버수사대 지망 진로에 맞는 포트폴리오로 정리하고 있습니다.

학업에서는 컴퓨터공학의 기본기인 프로그래밍, 자료구조, 네트워크, 운영체제, 데이터베이스 흐름을 바탕으로 보안 문제를 이해하려고 합니다. 대회와 수상 경험은 결과만 남기지 않고, 어떤 방식으로 문제를 읽고 가설을 세웠는지까지 다시 정리하는 방향으로 관리하고 있습니다.

## 현재 학습 내용

| 분야 | 현재 루틴 | 목표 산출물 |
| --- | --- | --- |
| 웹해킹 | HTTP 요청/응답, 인증·세션, 입력값 검증, OWASP Top 10 취약점 흐름 정리 | 취약점 재현 노트, 대응 우선순위, 프로젝트 분석 카드 |
| 리버싱 | 문자열, 함수 호출, 분기 조건, 디버거 기반 동적 분석 루틴 반복 | 분석 로그, 의심 함수 정리, 행위 기반 설명문 |
| 포렌식 | 해시 무결성, 로그 타임라인, 파일 흔적, 증거 보존 절차 학습 | 증거 목록, 타임라인 표, 조사 보고서 초안 |
| 보안관제 | 이벤트 탐지, 경보 판단, 상황 기록, 대응 흐름 이해 | 알림 분석 메모, 사고 흐름 요약, 관제 관점 체크리스트 |
| 문서화 | 분석 근거와 결론을 분리해 쓰는 훈련 | 포트폴리오 상세 페이지, 대회 풀이 기록, 자기소개서 기반 자료 |

## 앞으로의 계획

- 매주 한 가지 주제를 정해 `개념 정리 → 실습 → 증거 기록 → 대응 관점` 순서로 페이지화
- 대회 수상 자료와 프로젝트 결과물을 단순 이미지가 아니라 분석 역량의 근거로 연결
- 경찰간부후보생 시험 준비와 보안 실무 학습을 분리하지 않고, 공공 보안 직무에 필요한 판단력과 문서화 능력으로 통합
