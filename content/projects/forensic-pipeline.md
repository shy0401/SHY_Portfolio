## 프로젝트 개요

반복적인 포렌식 기초 작업을 자동화해 분석 시간을 줄이고, 증거 정리 형식을 표준화하기 위한 프로젝트입니다. 파일을 수집한 뒤 원본과 분석 사본을 구분하고, 해시값·파일 시그니처·메타데이터·타임라인을 일정한 형식으로 기록하는 흐름을 목표로 합니다.

이 프로젝트는 Autopsy, Wireshark, Ghidra 같은 공개 분석 도구에서 사용하는 증거 탐색·타임라인·파일 구조 확인 흐름을 기반으로 구성했습니다.

## 수행 내용

- 수집 파일 해시 계산 및 무결성 기록 자동화
- 이벤트 로그/타임라인 파싱 규칙 정리
- 증거 전달용 보고서 템플릿 설계 및 문서 구조 통일
- 파일 시그니처와 확장자 불일치 여부를 먼저 확인하는 점검 규칙 설계
- Hex 값, 문자열, 메타데이터, 파일 끝부분 데이터 확인 항목 정리
- 분석 전후 해시값, 수집 위치, 분석자 메모를 분리해 기록하는 표준 양식 구성

## 파이프라인 설계

| 단계 | 자동화/표준화 항목 | 산출물 |
| --- | --- | --- |
| 1. 수집 등록 | 파일명, 경로, 수집 시각, 수집 출처 입력 | 증거 목록 |
| 2. 무결성 계산 | SHA-256 등 해시값 계산 | 해시 기록표 |
| 3. 파일 구조 확인 | Magic Number, 확장자, 크기, 메타데이터 확인 | 파일 기본 분석표 |
| 4. 흔적 추출 | 문자열, 의심 URL, 삽입 데이터, 로그 필드 추출 | 단서 목록 |
| 5. 타임라인 구성 | 생성/수정/접근 시간, 로그 시간 정렬 | 사건 흐름표 |
| 6. 보고서 생성 | 요약, 증거, 분석, 판단, 한계 분리 | 보고서 초안 |

## 프로젝트 산출물

- 증거 목록 템플릿
- 해시 검증 기록표
- 파일 시그니처 점검 체크리스트
- 타임라인 표준 양식
- 사이버수사형 분석 보고서 초안 구조

## 결과

분석 재현성과 기록 일관성을 동시에 높여,  
사건 대응 시 빠른 검토와 협업이 가능한 포렌식 기반을 마련했습니다.

## 다음 개선 계획

- 간단한 스크립트 기반 해시 계산과 파일 목록 출력 자동화
- 웹 공격 로그와 파일 증거를 하나의 타임라인으로 합치는 예시 추가
- 리버싱 프로젝트 결과와 연결해 실행 파일이 남긴 흔적을 함께 정리
