## 개요

`2025학년도 AI 기반 이미지 생성 콘테스트 증서`와 `AI 이미지 생성대회 3등`은 같은 대회와 연결된 기록이므로, 포트폴리오에서는 하나의 통합 게시글로 관리합니다.

이 활동은 보안 분야 수상은 아니지만, 생성형 AI 도구를 활용해 주제를 해석하고 시각 결과물을 구성한 경험입니다. 보안 포트폴리오 관점에서는 프롬프트 설계, 결과 비교, 의도 전달, 산출물 설명 능력을 보여주는 보조 자료로 정리했습니다.

## 정리한 역량

| 역량 | 내용 |
| --- | --- |
| 프롬프트 설계 | 주제에 맞는 키워드와 시각 분위기를 단계적으로 조정 |
| 결과 비교 | 여러 생성 결과 중 메시지가 가장 분명한 이미지를 선별 |
| 산출물 설명 | 이미지가 전달하는 의미와 선택 이유를 짧고 명확하게 정리 |
| 포트폴리오 연결 | 개발/보안 분야에서도 AI 도구를 분석 보조와 문서화에 활용할 수 있다는 관점 확보 |

## 앞으로의 활용 계획

- 보안 보고서, 분석 다이어그램, 발표 자료에서 AI 도구를 보조적으로 활용
- 프롬프트 결과를 그대로 사용하는 것이 아니라, 근거와 의도에 맞게 재검토하는 습관 유지
- 사이버수사 준비 과정에서 시각 자료를 통해 복잡한 사건 흐름을 설명하는 훈련으로 확장
