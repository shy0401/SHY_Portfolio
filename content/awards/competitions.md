## 개요

정보보호 대회와 실전형 미니챌린지는 제 학습 방향을 검증하는 중요한 기준입니다. 단순히 문제를 푸는 데서 끝내지 않고, 문제 접근 방식, 증거 정리, 팀 커뮤니케이션, 발표 가능한 결과 정리까지 하나의 학습 루틴으로 기록하고 있습니다.

## 주요 수상 성과

| 구분 | 성과 | 의미 |
| --- | --- | --- |
| 2025 호남권 정보보호 특별과정 미니챌린지 | 한국인터넷진흥원장상 대상 | 제한 시간 안에서 취약점 분석, 문제 해결, 결과 정리를 수행한 실전형 성과 |
| 2025 호남지역 정보보호 해커톤 | 호남정보보호지원센터장상 동상 | 정보보호 해커톤 환경에서 협업 기반 문제 해결 능력을 검증 |
| 2021 BCG 해킹대회 | 은상, 2등 | 1학년 때 리버싱·포렌식·네트워크·웹 취약점 문제를 접하며 보안 학습 방향을 잡은 초기 성과 |
| KISA 해킹대회 | 1등 | 실전형 문제 해결 속도와 정확도를 끌어올린 성과 |
| KISA 해킹대회 | 3등 | 반복 참가를 통해 취약점 재현과 풀이 근거 정리 능력을 강화 |
| 2025학년도 AI 기반 이미지 생성 콘테스트 | 3등 | 생성형 AI를 활용한 주제 해석과 시각 콘텐츠 구성 역량을 확인 |
| 계룡대근무지원단 장병 독후감 공모전 | 우수상 | 보안 분야에 필요한 글쓰기, 구조화, 설득력 있는 표현 역량을 확장 |

## 활동 및 예정

- 세종 핵테온 참가예정
- 보안 대회 풀이 과정을 프로젝트 문서와 연결
- 대회 경험을 사이버수사 준비 관점의 분석 보고서 형태로 재정리
- 육군본부 사이버작전센터 사이버관제병 경력증명서 항목은 경력 기록에 반영하고, 증빙 파일이 준비되면 다운로드 자료에 연결 예정

## 앞으로의 계획

- 문제 유형별로 `접근 가설 → 재현 과정 → 확인 근거 → 대응 관점` 순서의 풀이 로그 작성
- 웹해킹, 리버싱, 포렌식 문제를 각각 독립 기록으로 남기고 프로젝트 페이지와 연결
- 사이버수사대 지망 진로에 맞춰 기술 분석 결과를 사건 흐름 중심으로 설명하는 훈련 지속
