## 개요

핵심 역량을 웹해킹, 리버싱, 포렌식, 사이버수사 준비 네 축으로 나누고, 각 축을 다시 기초·실습·문서화·프로젝트 연결 단계로 관리하고 있습니다. 목표는 “많이 공부했다”가 아니라 “무엇을 어떤 순서로 익히고, 어떤 결과물로 남겼는지”가 보이는 포트폴리오를 만드는 것입니다.

## 4축 학습 계획

| 축 | 1차 목표 | 2차 목표 | 포트폴리오 결과물 |
| --- | --- | --- | --- |
| 웹해킹 | OWASP Top 10, HTTP, 인증/인가 흐름 이해 | SQLi, XSS, 파일 업로드, 세션 취약점 재현 | 웹 보안 프로젝트, 취약점 재현 노트 |
| 리버싱 | PE 구조, 문자열, 함수 호출 흐름 파악 | 디버거 기반 동적 분석과 행위 설명 | 리버싱 학습 프로젝트, 분석 로그 |
| 포렌식 | 해시, 증거 보존, 로그 필드 정리 | 타임라인 재구성과 보고서 초안 작성 | 포렌식 자동화 프로젝트, 증거 목록 |
| 사이버수사 | 사건 흐름, 판단 근거, 대응 우선순위 정리 | 기술 보고서와 사건 요약문 분리 작성 | 진로 목표 페이지, 사이버수사 준비 페이지 |

## 진행 성과

- 수상 기록과 증빙 이미지를 대회·자격·갤러리 페이지에 분리 연결
- 프로젝트 3개를 각각 웹해킹, 리버싱, 포렌식 축과 연결
- KISA/호남권 정보보호 대회 성과를 학습 흐름 안에 재배치
- 사이버관제병 경력 기록을 사이버수사 준비와 보안관제 관점으로 연결

## 앞으로의 계획

- 월 1회 이상 핵심 역량 페이지 업데이트
- 대회 문제 풀이를 `문제 상황 → 분석 가설 → 증거 → 판단 → 대응` 형식으로 재작성
- 증빙 자료가 추가될 때마다 다운로드와 갤러리 경로 동시 갱신
- 세종 핵테온 참가 후 활동 기록과 프로젝트 산출물로 연결
