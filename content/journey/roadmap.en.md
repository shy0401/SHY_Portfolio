## Overview

This roadmap divides my core learning into web hacking, reversing, forensics, the Korean police patrol officer exam, and cyber investigation preparation. Each track is managed through fundamentals, practice, documentation, and project connection.

## Four-Track Plan

| Track | First Goal | Second Goal | Portfolio Output |
| --- | --- | --- | --- |
| Web Hacking | Understand OWASP Top 10, HTTP, auth/access flow | Reproduce SQLi, XSS, file upload, and session issues | Web security project and vulnerability notes |
| Reversing | Read PE structure, strings, and function-call flow | Explain behavior through debugger-based dynamic analysis | Reversing project and analysis logs |
| Forensics | Organize hashes, evidence handling, and log fields | Reconstruct timelines and draft reports | Forensic automation project and evidence lists |
| Police Exam | Complete TOEIC and Korean History requirements, then prepare criminal law, constitutional law, and police studies | Extend preparation to physical and interview stages | Certificates page and career goal page |
| Cyber Investigation | Organize incident flow, reasoning, and response priority | Separate technical report and case summary | Career goal and cyber investigation pages |
