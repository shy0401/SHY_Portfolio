## 개요

리버싱 학습은 실행 파일이 어떤 흐름으로 동작하는지 추적하고, 관찰한 행위를 근거 중심으로 설명하는 역량을 기르는 과정입니다. 현재는 기초 바이너리 분석 루틴을 반복하면서 정적 분석과 동적 분석의 역할을 구분해 기록하고 있습니다.

지금은 입력값 길이, 실행 결과 문자열, 파일 내부 구조를 확인하는 과정을 “어떤 단서가 있었고, 어떤 방식으로 검증했는지” 기준으로 다시 정리하고 있습니다.

## 학습 로드맵

| 단계 | 학습 주제 | 구체적 실습 |
| --- | --- | --- |
| 1단계 | 실행 파일 구조 | PE 구조, 섹션, 엔트리포인트, 임포트 테이블 확인 |
| 2단계 | 기초 정적 분석 | 파일 해시, 파일 시그니처, 문자열, 함수명, 의심 API 호출 정리 |
| 3단계 | 입력값/분기 추적 | 입력 길이, 비교 문자열, 조건 분기, 성공/실패 메시지 확인 |
| 4단계 | 동적 분석 | 디버거로 레지스터, 스택, 메모리, 함수 호출 흐름 관찰 |
| 5단계 | 취약 동작 이해 | Buffer Overflow, 경계값, 메모리 범위 초과 가능성 정리 |
| 6단계 | 행위 해석 | 파일 생성, 네트워크 접근, 레지스트리 변경 가능성 정리 |
| 7단계 | 보고서화 | 의심 지점, 근거, 재현 방법, 보안적 의미를 문서화 |

## 실제 활동에서 연결한 리버싱 주제

| 활동/문제 | 확인한 단서 | 현재 학습으로 확장한 부분 |
| --- | --- | --- |
| Reversing_1 - Buffer_Overflow | 제목 자체가 힌트였고, 입력 길이와 성공 문자열이 핵심 단서 | 경계값, 버퍼 크기, 입력 검증 부재를 분석하는 루틴으로 확장 |
| 실행 결과 문자열 확인 | 콘솔 출력에서 `Success` 계열 문자열을 확인 | 문자열 검색과 조건 분기 추적의 출발점으로 활용 |
| Hex/파일 구조 확인 | 파일 내부 바이트와 시그니처를 비교 | 정적 분석에서 파일 형식과 헤더를 먼저 확인하는 습관으로 연결 |
| 대회 풀이 정리 | 문제별 풀이 과정을 이미지와 문장으로 정리 | 리버싱 결과를 포렌식·사이버수사 보고서형 설명으로 재구성 |

## 분석 루틴 상세

| 구분 | 확인 항목 | 기록 방식 |
| --- | --- | --- |
| 파일 기본 정보 | 파일명, 확장자, 해시, 크기, 실행 가능 여부 | 분석 시작 전 표로 정리 |
| 문자열 분석 | 성공/실패 메시지, URL, 파일 경로, 의심 키워드 | 문자열과 추정 의미를 분리해 기록 |
| 함수 흐름 | 입력 처리 함수, 비교 함수, 출력 함수 | 호출 흐름을 간단한 순서도로 정리 |
| 동적 관찰 | 레지스터, 스택 변화, 분기 결과, 메모리 변화 | 디버거 관찰값과 결론을 분리 |
| 취약 동작 | 입력 길이 제한 부재, 경계값 오류, 검증 누락 | 재현 조건과 보안적 의미를 함께 작성 |
| 보고서화 | 단서, 검증 과정, 결론, 한계 | 사이버수사 관점의 사건 흐름 문장으로 요약 |

## 현재 반복 루틴

- 작은 실습 바이너리부터 시작해 함수 단위로 흐름을 끊어 읽기
- 문자열과 API 호출을 먼저 확인하고, 실제 실행 흐름과 비교
- 디버거 관찰 결과를 스크린샷이나 표 형태로 남기고 분석 결론과 분리
- 분석 표현 방식과 기록 문장을 일관된 형식으로 정리
- CTF/대회 문제는 정답만 저장하지 않고 입력값, 실행 결과, 단서, 풀이 근거를 함께 정리
- 리버싱 문제에서 나온 파일 구조 단서를 포렌식 학습과 연결해 재검토

## 진행 성과

- 리버싱 노트 템플릿 표준화
- 분석 결과를 프로젝트 페이지와 연결 가능한 형식으로 정리
- 리버싱 학습 프로젝트에서 `정적 단서 → 동적 검증 → 행위 설명` 구조 반영
- 사이버수사 준비 페이지와 연결해 기술 분석을 사건 흐름으로 설명하는 훈련 진행
- Ghidra 등 분석 도구 기반 루틴을 정적 단서와 동적 검증 과정에 연결
- Buffer Overflow 문제를 입력 검증, 경계값, 실행 흐름 분석 관점으로 다시 정리

## 앞으로의 계획

- 난독화, 패킹, 안티디버깅 기초 개념을 순차적으로 학습
- 간단한 악성 행위 시나리오를 만들어 분석 로그와 대응 관점을 함께 정리
- 포렌식 타임라인과 리버싱 결과를 연결해 “실행 파일이 남긴 흔적”을 설명하는 연습 추가
- 리버싱 결과를 비전문가도 이해할 수 있는 요약문으로 작성
- 도구 화면, 실습 캡처, 분석 노트를 분리해 리버싱 근거를 계속 축적
- 디버거 관찰 결과를 사이버수사 보고서형 문장으로 바꾸는 연습 강화
