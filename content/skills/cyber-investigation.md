## 개요

사이버수사 준비는 웹해킹, 리버싱, 포렌식 지식을 하나로 묶어 사건을 이해하고 설명하는 훈련입니다. 경찰순경시험 준비와 병행하면서 공공 보안 분야에서 필요한 판단력, 책임감, 체력, 면접 표현력, 문서화 능력을 함께 키우는 것을 목표로 합니다.

현재는 경찰순경시험 응시에 필요한 영어·한국사 인증 조건을 완료한 상태에서, 1차 필기 과목인 형법·헌법·경찰학개론을 중심으로 학습하고 있습니다. 이후 2차 체력, 3차 면접까지 이어지는 흐름을 염두에 두고 체력 루틴과 면접 답변 키워드도 함께 정리하고 있습니다.

## 준비 로드맵

| 축 | 준비 내용 | 포트폴리오 반영 |
| --- | --- | --- |
| 기술 분석 | 웹 취약점, 바이너리 행위, 로그/증거 분석을 분리 학습 | 핵심 역량 상세 페이지와 프로젝트 페이지 |
| 상황 판단 | 공격 흐름, 영향 범위, 피해 가능성, 대응 우선순위 정리 | 대회 풀이와 프로젝트 분석 요약 |
| 증거 관리 | 해시, 타임라인, 원본/사본 구분, 근거 보존 | 포렌식 학습 페이지와 증빙 자료 |
| 문서 작성 | 기술 보고서, 사건 요약, 자기소개서형 설명문 작성 | 프로필, 진로 목표, 수상 페이지 |
| 응시 조건 | TOEIC과 한국사검정능력시험 인증 완료 | 자격/어학/증빙 페이지 |
| 1차 필기 | 형법, 헌법, 경찰학개론 학습 루틴 구축 | 진로 목표 페이지와 학습 로드맵 |
| 2·3차 전형 | 체력 루틴, 면접 답변, 자기소개 흐름 준비 | 성장 타임라인과 자기소개 정리 |
| 공공 진로 | 경찰순경시험 준비와 보안 실무 학습 병행 | 진로 목표 페이지와 성장 타임라인 |

## 시험 준비 세부 계획

| 단계 | 현재 상태 | 관리 방식 |
| --- | --- | --- |
| 영어 인증 | TOEIC 650 보유 | 자격/어학/증빙 페이지에서 성적표 다운로드 연결 |
| 한국사 인증 | 한국사검정능력시험 인증서 보유 | 인증 PDF를 다운로드 자료로 연결 |
| 1차 필기 | 형법·헌법·경찰학개론 중심 학습 | 조문/판례/개념/기출을 분리해 체크리스트화 |
| 2차 체력 | 기초 체력과 기록 관리 준비 | 운동 루틴, 측정 기록, 약점 보완 항목을 주기적으로 관리 |
| 3차 면접 | 자기소개, 지원동기, 직무 이해 정리 | 사이버수사대 지망 이유와 보안 활동 경험을 답변 키워드로 정리 |
| 사이버수사 역량 | 웹해킹·리버싱·포렌식 활동 연결 | 대회 풀이를 사건 흐름과 증거 기반 보고서 형태로 재작성 |

## 사이버수사대 지망 역량 매핑

| 요구 역량 | 내 준비 내용 | 실제 근거 |
| --- | --- | --- |
| 사건 흐름 이해 | 공격 벡터, 취약점, 로그, 파일 흔적을 하나의 시간순 흐름으로 정리 | BCG 해킹대회 풀이 이미지, 웹해킹/포렌식 학습 기록 |
| 증거 보존 관점 | 원본/사본 구분, 해시, 파일 시그니처, 메타데이터 확인 | 포렌식 학습 페이지와 포렌식 자동화 프로젝트 |
| 기술 분석력 | 웹 취약점, Buffer Overflow, Path Traversal, XSS, 파일 구조 분석 | 웹해킹·리버싱·포렌식 상세 페이지 |
| 보고서 작성력 | 기술 근거와 판단 근거를 분리해 설명 | 독후감 공모전 우수상, 포트폴리오 상세 문서 |
| 실전 문제 해결 | 제한 시간 안에서 문제 유형을 분류하고 풀이 방향 결정 | KISA/호남권 정보보호 활동, BCG 해킹대회 |
| 공직 준비 태도 | 경찰순경시험 필기·체력·면접 준비 병행 | TOEIC, 한국사 인증, 형법·헌법·경찰학개론 학습 루틴 |

## 현재 반복 루틴

- 매주 한 분야의 실습을 선택해 사건 흐름 관점으로 다시 설명
- 분석 결과를 “기술 근거”와 “판단 근거”로 나눠 작성
- 형법·헌법·경찰학개론은 개념 정리와 기출 회독을 분리해 관리
- 체력과 면접은 2·3차 전형을 고려해 루틴과 답변 키워드 형태로 정리
- 사이버관제병 경력 기록을 바탕으로 탐지 이벤트와 대응 기록의 중요성 정리
- 수상 이미지와 증빙 자료를 단순 첨부가 아니라 성과 근거로 연결

## 분석 보고 연습 흐름

| 순서 | 질문 | 산출물 |
| --- | --- | --- |
| 1. 수집 | 어떤 로그, 파일, 화면, 증빙을 확보했는가? | 증거 목록과 원본 경로 |
| 2. 무결성 | 원본과 분석 사본이 분리되었고 해시가 기록되었는가? | 해시값, 수집 시각, 보관 위치 |
| 3. 분석 | 취약점, 행위, 흔적이 어떤 근거로 확인되는가? | 분석 표, 캡처, 재현 조건 |
| 4. 타임라인 | 행위가 어떤 순서로 발생했는가? | 시간순 사건 흐름표 |
| 5. 판단 | 사실과 추정을 분리했는가? | 판단 근거와 한계 |
| 6. 보고 | 비전문가도 이해할 수 있게 설명했는가? | 요약문, 대응 제안, 후속 확인 사항 |

## 진행 성과

- 대회/프로젝트 결과를 진로 준비 관점으로 재정리
- TOEIC 650과 한국사검정능력시험 인증 조건 완료
- 포트폴리오 내 허브/상세 구조로 학습 기록 체계화
- 2025 호남권 정보보호 특별과정 미니챌린지 대상과 호남지역 정보보호 해커톤 동상을 통해 실전형 보안 문제 대응 경험 강화
- 독후감 공모전 우수상 경험을 통해 장문 문서화와 설득적 표현 역량 보완
- 경찰순경시험 준비 요건 이미지를 직접 제작해 현재 조건 완료와 다음 준비 단계를 시각적으로 정리
- 대회 활동 이미지를 사이버수사형 분석 보고 흐름과 연결

## 앞으로의 계획

- 세종 핵테온 참가를 통한 현장형 문제 대응 경험 축적
- 형법·헌법·경찰학개론 1차 필기 학습 루틴 고도화
- 체력 및 면접 준비를 위한 생활 루틴과 답변 구조 지속 보완
- 사이버수사 관점의 포트폴리오 문서 완성도 향상
- 보안 대회 문제를 “수사 보고서 초안” 형태로 재작성
- 사이버수사 관련 공개 판례·보안 사고 보고서를 읽고 기술 설명과 법적 표현의 차이 정리
- 경찰 채용공고 변경 사항은 공식 공고 기준으로 주기적으로 확인하고 포트폴리오 문구를 갱신
