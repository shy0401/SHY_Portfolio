## Overview

Cyber investigation preparation connects web hacking, reversing, and forensics into a single ability: understanding and explaining an incident. While preparing for the Police Officer Candidate Exam, I aim to build judgment, responsibility, and documentation skills required in public security.

## Preparation Roadmap

| Axis | Preparation | Portfolio Reflection |
| --- | --- | --- |
| Technical Analysis | Study web vulnerabilities, binary behavior, logs, and evidence separately | Core skill pages and project pages |
| Situational Judgment | Organize attack flow, impact scope, damage possibility, and response priority | Competition writeups and project summaries |
| Evidence Management | Hashes, timelines, original/copy separation, evidence preservation | Forensics page and proof materials |
| Documentation | Technical reports, case summaries, personal statement-style explanation | Profile, career goal, awards pages |
| Public Career | Combine exam preparation with security practice | Career goal and growth timeline pages |
