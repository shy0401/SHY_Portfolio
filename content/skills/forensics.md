## 개요

포렌식 학습은 디지털 흔적을 발견하고, 증거로서 신뢰할 수 있도록 보존하며, 사건 흐름으로 설명하는 과정입니다. 저는 사이버수사대 지망 진로에 맞춰 증거 수집 절차, 무결성 검증, 타임라인 재구성, 보고서 작성까지 하나의 흐름으로 공부하고 있습니다.

지금은 파일 시그니처, Hex 값, 이미지 구조, 숨겨진 문자열 단서를 “원본 보존 → 단서 추출 → 의미 해석 → 보고서화” 흐름으로 정리하고 있습니다.

## 학습 로드맵

| 단계 | 학습 주제 | 구체적 실습 |
| --- | --- | --- |
| 1단계 | 증거 보존 | 원본/사본 구분, 해시값 기록, 파일 메타데이터 확인 |
| 2단계 | 파일 기본 분석 | 파일 시그니처, 확장자 불일치, Magic Number, Hex 값 확인 |
| 3단계 | 숨겨진 흔적 탐색 | 문자열, 이미지 내부 데이터, 압축/삽입 흔적, 메타데이터 확인 |
| 4단계 | 로그 분석 | 웹 로그, 시스템 로그, 이벤트 시간 정렬 |
| 5단계 | 파일 흔적 | 삭제 파일, 압축 파일, 다운로드 흔적, 실행 흔적 정리 |
| 6단계 | 타임라인 | 행위 발생 순서를 시간축으로 재구성 |
| 7단계 | 보고서화 | 증거 목록, 분석 근거, 결론, 한계점을 분리해 작성 |

## 실제 활동에서 연결한 포렌식 주제

| 활동/문제 | 확인한 단서 | 현재 학습으로 확장한 부분 |
| --- | --- | --- |
| Forensic_1 - My_Signature_Letter_Is | 파일 시그니처와 내부 구조가 단서로 사용됨 | 확장자와 Magic Number가 맞는지 먼저 확인하는 루틴으로 확장 |
| Forensic_2 - What_Does_BCG_Mean | Hex 값, 이미지 헤더, 숨겨진 문자열 흐름 확인 | Hex Editor 기반 파일 구조 분석과 숨겨진 데이터 추출 연습으로 연결 |
| 이미지 파일 분석 | PNG/JPG 헤더, 데이터 영역, 의심 문자열 비교 | 메타데이터, 파일 끝부분, 삽입 데이터 점검 체크리스트로 확장 |
| 대회 풀이 기록 | 문제별 풀이 화면과 설명을 남김 | 포렌식 보고서의 증거 캡처와 분석 근거 분리 방식으로 재정리 |
| 네트워크/경로 문제와 연결 | URL, 경로, 파일 접근 흔적 확인 | 웹 로그와 파일 접근 기록을 하나의 사건 타임라인으로 묶는 연습 |

## 증거 분석 체크리스트

| 분류 | 확인 질문 | 기록 방식 |
| --- | --- | --- |
| 원본 보존 | 원본 파일과 분석용 사본이 분리되었는가? | 파일명, 경로, 해시값을 먼저 기록 |
| 무결성 | 분석 전후 해시값이 동일한가? | SHA-256 등 해시값과 계산 시점 기록 |
| 파일 구조 | 확장자와 Magic Number가 일치하는가? | 헤더 바이트와 예상 파일 형식 비교 |
| 숨겨진 흔적 | 문자열, 메타데이터, 삽입 데이터가 존재하는가? | 발견 위치, 추출 방법, 의미를 분리 작성 |
| 시간 정보 | 생성/수정/접근 시간이 사건 흐름과 맞는가? | 시간대를 통일하고 타임라인 표로 정리 |
| 보고서화 | 증거와 추정이 분리되어 있는가? | 사실, 해석, 한계, 추가 확인 사항을 구분 |

## 현재 반복 루틴

- 해시값을 먼저 계산하고 분석 전후 변경 여부를 확인
- 로그에서 IP, 계정, 시간, 요청 경로, 이벤트 ID를 분리해 표로 정리
- 포렌식 자동화 프로젝트와 연결해 반복 가능한 수집/정리 절차를 구성
- 포렌식 용어와 절차 표현을 일관된 기준으로 정돈
- Hex Editor로 파일 헤더와 시그니처를 확인하고, 확장자와 실제 파일 형식이 맞는지 비교
- 이미지/문서 파일은 메타데이터, 문자열, 끝부분 데이터, 삽입 흔적을 별도 체크리스트로 점검

## 진행 성과

- 증거 정리 템플릿 구성
- 포렌식 자동화 프로젝트에 절차 반영
- 수상/경력 증빙 자료를 포트폴리오 내에서 파일 경로와 설명으로 분리 관리
- 보안관제 경험 기록과 연결해 탐지 이벤트가 조사 자료로 이어지는 흐름을 정리
- Autopsy 기반 분석 루틴을 증거 탐색과 분석 근거 정리 과정에 연결
- 파일 시그니처와 Hex 분석 흐름을 포렌식 학습 페이지에 구체적으로 정리

## 앞으로의 계획

- 웹 공격 로그 기반 사건 시나리오를 만들어 증거 흐름 연습
- 리버싱 결과와 포렌식 흔적을 연결해 실행 파일 분석 후 남는 이벤트 정리
- 조사 보고서 초안을 `요약 → 증거 → 분석 → 판단 → 대응` 순서로 작성
- 사이버수사 준비 페이지와 연결해 법적·윤리적 증거 보존 관점 보완
- 도구 화면과 실습 캡처를 분리해 증거 캡처와 분석 근거를 계속 축적
- 웹해킹/리버싱 결과와 포렌식 증거를 하나의 타임라인으로 묶는 연습 강화
