## 개요

웹 서비스의 취약점을 재현하고 위험도를 평가한 뒤  
대응 우선순위를 정리하는 학습에 집중하고 있습니다.

## 현재 학습 내용

- 입력 검증 취약점(SQLi/XSS) 재현 테스트
- 인증/세션 로직 점검 항목 정리
- 취약점 영향도를 서비스 관점으로 설명하는 문서 작성

## 진행 성과

- PoC 기반 재현 기록 템플릿 정리
- 웹 보안 프로젝트 페이지에 분석 흐름 반영

## 앞으로의 계획

- 케이스별 대응 가이드를 페이지 형태로 추가
- 프로젝트와 연결된 취약점 대응 로그 정리
